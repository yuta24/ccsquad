## アンチパターン（避けるべき定義）

### 曖昧な役割定義

```markdown
# Developer

コードを書くエージェント。
```

問題: Generator/Evaluator の位置づけ不明。担当フェーズ不明。

### ツール過剰付与

```markdown
---
tools: Read, Write, Edit, Glob, Grep, Bash, Agent, WebFetch, WebSearch
---

# Reviewer
```

問題: Evaluator に Write/Edit が含まれており、Generator-Evaluator 分離に違反。

### 出力契約なし

```markdown
## 作業内容

1. コードを読む
2. 問題を見つける
3. 報告する
```

問題: result/message の形式が未定義。run-job スキルが結果を解釈できない。

### 汎用的すぎるルール

```markdown
## ルール

- 良いコードを書く
- テストを忘れない
```

問題: 判断基準が不明確。具体的な禁止事項がない。
